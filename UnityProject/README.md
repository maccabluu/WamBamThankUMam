# Wam Bam Thank U Mam - Unity Alpha 0.5

Unity 6.3 LTS rebuild of the match-3 game.

## Included

- 8 x 8 match-3 board
- Animated Heart, Lipstick, Cherries, Diamond, Star and Heel pieces
- 16 moves
- Cherry, Diamond and Star targets
- Coins and lives
- Rocket, Hammer, Disco Ball and Swap boosters
- Portrait mobile UI aligned to the supplied comic lounge references
- Android package `com.blustudio.wambam`
- One-click editor build command: `Wam Bam > Build Android APK`

The APK output is `Builds/Android/WamBamThankUMam-Alpha-0.5.apk`.

The Unity conversion remains on a draft branch until the Android build is visually checked.
