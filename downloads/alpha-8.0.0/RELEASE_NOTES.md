# Wam Bam Alpha 8.0.0

Alpha 8.0 refreshes Levels 1 to 5 around the new lounge gameplay artwork.

## Changes

- Levels 1, 2, 3, 4 and 5 now use the new updated gameplay background.
- Removed the old Coins and Hearts HUD readouts from the gameplay screen to match the new artwork.
- Repositioned the Moves and Target information for the new top panels.
- Expanded the playable board to match the new artwork, with 8 cells across and 11 cells down.
- Updated match checking, drops, cascades, reshuffles, boosters and Level 5 handbag blockers for the taller board.
- Resized gameplay icons so they sit inside the new grid cells.
- Kept Android portrait scaling and 60 FPS game settings.
- Updated the internal GDevelop project version to 8.0.0.

## Package

`com.macca.wambamthankumam`

## Build note

The Alpha 8.0 APK is built from the Alpha 7.9 gameplay package with the new background and board update applied.
