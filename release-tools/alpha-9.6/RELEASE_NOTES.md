# Wam Bam Alpha 9.6.0

- Uses the supplied illustrated road map, with working level buttons over ten gold markers per area, four area tabs, saved ratings and level previews.
- Levels 1 to 9 now use the same square tile style and shaped boards as later levels. Handbags stay on playable cells. Existing targets, progress and square-to-Disco rules are retained.
- Levels 21 to 30 use the supplied Disco Diner artwork. Other gameplay backgrounds stay unchanged.
- All 40 levels, special combinations and area decorations remain available.

Package: `com.macca.wambamthankumam`. Version: `9.6.0` (`96000`). Signed with the existing Wam Bam identity so this installs as an update.

Automated validation covers board rules, starting layouts, cascades, road map controls, background selection, touch input and phone/tablet layout. Physical-device playtesting is still needed.
