# Wam Bam Alpha 11.0.3

Replaces the level backgrounds with the supplied lounge artwork across all 100 campaign levels. Repositions the board, live moves and targets, booster touch areas and pause control to match the new image.

Built from Alpha 11.0.2. Retains the existing gameplay, saves, room upgrades, home lights, pre-game guides, pink locks and booster inventory. The artwork is included at its original resolution without recompression.

Android package: com.macca.wambamthankumam. Signed with the existing Wam Bam identity and checked against the base APK certificate.

Validation covers background selection, phone and tablet layout, booster selection, pause/resume, a playable swap and live move counters. Physical Android testing is still needed.
