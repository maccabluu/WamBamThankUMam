# Wam Bam Thank U Mam Public Alpha 0.1

This build is for public testing.

## Current test scope

- Home screen
- Road Map
- Level 1
- Match-3 gameplay
- Settings screen
- Replay and Home controls on the Out of Moves screen

## Please report

- Crashes
- Buttons that do not respond
- Touch or swipe problems
- Screen scaling problems
- Missing artwork
- Level progression problems
- Performance problems

## Include with every bug report

- Device model
- Android or iOS version
- What you pressed before the problem happened
- Screenshot or screen recording if possible

Build base: Alpha 6.9
