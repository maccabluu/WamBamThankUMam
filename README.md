# Wam Bam Thank U Mam

Native Android match-3 game in Alpha by BluStudio.

## Latest Android build: Alpha 11.6.2 Testing Level Fixes

- [Download Wam Bam Alpha 11.6.2 APK](https://github.com/maccabluu/WamBamThankUMam/releases/download/v11.6.2/WamBam_Alpha_11.6.2_Test_Level_Selection_Fix.apk)
- [Open the Alpha 11.6.2 release](https://github.com/maccabluu/WamBamThankUMam/releases/tag/v11.6.2)

Alpha 11.6.2 fixes the testing problems shown in the latest video. Choosing a testing level such as Level 195 now opens Level 195 instead of falling back to the player's real next level. The bottom PLAY LEVEL button also follows the currently selected testing level.

Android package: `com.macca.wambamthankumam`

Version: `11.6.2`

Version code: `116002`

Signing certificate SHA-256: `d04c069c47d1642c83243de681e62bfd1a5c996816ab0c7b15dea82a91338ad1`

The build keeps the permanent Wam Bam signing identity so it installs over the previous signed game.

## Current game features

- 200 campaign levels
- Levels 101-200 added in Alpha 11.6.0
- Temporary testing access to Levels 1-200
- High testing levels now launch the exact selected level
- Testing future levels does not advance normal saved progression
- Match-3 gameplay with touch and swipe controls
- Wam World and Road Map navigation
- Level Map and campaign progression
- Frankie Flash Level 10 boss battle
- Bam Lounge upgrade flow
- Saved progress, stars and boosters
- Hammer, Mic Blast, Shuffle, Spotlight and Jukebox boosters
- Bomb, rocket and Disco-style special pieces
- Wam Bam level backgrounds and artwork
- Settings and Home navigation
- Android phone and tablet support

## Testing note

The all-level testing access is temporary. Testing a future level such as Level 195 does not change the player's real completed-level or unlocked-level progress. When development testing is finished, normal level locking can be restored from the existing save.
