# Wam Bam Thank U Mam

Native Android match-3 game in Alpha by BluStudio.

Alpha 11.6.3 fixes the campaign map ordering. Levels now appear in strict numerical order, with Level 101 directly after Level 100, continuing through Level 200.

Android package: `com.macca.wambamthankumam`

The build keeps the permanent Wam Bam signing identity so it installs over the previous signed game.

## Current game features

- 200 campaign levels
- Strict map order from Level 1 through Level 200
- Level 101 follows Level 100
- Temporary testing access to Levels 1-200
- High testing levels launch the exact selected level
- Testing future levels does not advance normal saved progression
- Match-3 gameplay with touch and swipe controls
- Wam World and Road Map navigation
- Level Map and campaign progression
- Frankie Flash Level 10 boss battle
- Bam Lounge upgrade flow
- Saved progress, stars and boosters
- Hammer, Mic Blast, Shuffle, Spotlight and Jukebox boosters
- Bomb, rocket and Disco-style special pieces
- Wam Bam level backgrounds and artwork
- Settings and Home navigation
- Android phone and tablet support

The all-level testing access is temporary. Testing a future level does not change the player's real completed-level or unlocked-level progress. Normal level locking can be restored later from the existing save.
