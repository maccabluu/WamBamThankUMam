# Wam Bam Thank U Mam

Native Android match-3 game in Alpha by BluStudio.

## Latest Android build: Alpha 11.1.5

- [Download Wam Bam Alpha 11.1.5 APK](https://github.com/maccabluu/WamBamThankUMam/releases/download/v11.1.5/WamBam_Alpha_11.1.5_Install_Recovery.apk)
- [Open the Alpha 11.1.5 release](https://github.com/maccabluu/WamBamThankUMam/releases/tag/v11.1.5)

Alpha 11.1.5 is the install-recovery build for the current Wam Bam game. It keeps the Alpha 11.1.4 game content and fixes Android update compatibility by using a higher version code while keeping the permanent Wam Bam signing identity.

Android package: `com.macca.wambamthankumam`

Version: `11.1.5`

Version code: `111500`

Signing certificate SHA-256: `d04c069c47d1642c83243de681e62bfd1a5c996816ab0c7b15dea82a91338ad1`

The build workflow verifies the signing certificate against the existing Wam Bam update chain before publishing the APK.

## Current game features

- Match-3 gameplay with touch and swipe controls
- Wam World and Road Map navigation
- Level Map and campaign progression
- Bam Lounge upgrade flow
- Saved progress, stars and boosters
- Bomb, rocket and Disco-style special pieces
- Level backgrounds and Wam Bam artwork
- Settings and Home navigation
- Android phone and tablet support
